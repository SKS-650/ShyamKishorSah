⚡ AI Healthcare Assistant for Rural Areas

💪 Overview

An intelligent healthcare assistant designed specifically for rural communities in Nepal and similar developing regions lacking specialist medical access. The system provides symptom analysis, preliminary disease prediction, and evidence-based medical guidance via a mobile app that works in low-bandwidth environments.

🔥 Problem Statement

Millions of people in rural Nepal have no access to doctors or specialists. Basic healthcare decisions are often delayed or wrong due to lack of information. This project aims to bridge that critical gap using AI.

🧩 Key Features

  • Symptom-to-diagnosis NLP pipeline with medical knowledge base
  • Multi-language support (Nepali and English)
  • Offline-capable Flutter mobile app for low-connectivity areas
  • Disease risk assessment with confidence scores
  • Emergency escalation alerts with nearest health facility suggestions
  • FastAPI backend with TensorFlow NLP models

🧪 Face Disease Detection System

💪 Overview

A deep learning computer vision system that detects and classifies facial skin diseases and conditions. Built with PyTorch and fine-tuned ResNet architectures on dermatological image datasets, the system provides real-time analysis via webcam or image upload.

🧩 Key Features

  • Multi-class skin condition classification (10+ categories)
  • Custom CNN + transfer learning with ResNet-50
  • Real-time webcam inference at 30+ FPS
  • Confidence score visualization with Grad-CAM heatmaps
  • Dataset augmentation pipeline for improved generalization
  • REST API for mobile/web integration

🔨 Architecture

Input image → preprocessing pipeline → ResNet-50 backbone (fine-tuned) → custom classification head → softmax output with confidence scores. Grad-CAM used for explainability.

🛍️ ShopNepal — Online Shopping App

Version 2.0 · Production Ready · Last Updated: February 2025

📋 Overview

ShopNepal is a complete, production-ready Django e-commerce platform tailored for Nepal's market. It supports the full online shopping lifecycle — from product browsing and wishlist management to coupon-discounted checkout and payment via Nepal's most popular digital wallets (eSewa & PhonePe), plus Cash on Delivery. The platform ships with a staff-only admin analytics dashboard built with Chart.js.

✨ Key Features

  • Shopping Cart — Persistent cart with real-time price calculations and quantity management
  • Coupon System — Create percentage or fixed-amount discount codes; AJAX live validation at checkout
  • eSewa Integration — Nepal's most popular digital wallet with real-time transaction verification
  • PhonePe Integration — Indian digital payment in sandbox and production modes
  • Cash on Delivery — Instant order confirmation with admin fulfilment tracking
  • Wishlist — Save and manage favourite products for later purchase
  • Product Reviews — Customer star ratings and feedback per product
  • Order Tracking — Real-time order status updates and complete order history
  • Email Notifications — Automatic HTML order confirmation emails via SMTP
  • Admin Dashboard — Sales metrics, 7-day Chart.js trend, top products & coupons; staff-only access
  • Dark Mode — Light/dark theme toggle with Bootstrap 5 purple brand theme
  • Responsive Design — Fully optimised for mobile, tablet, and desktop

🗺️ Architecture

Modular Django app structure separating concerns cleanly: cart → coupons → orders → payments → notifications. Django ORM with SQLite3 for development; PostgreSQL-ready for production. CSRF protection, session-based auth, and server-side input validation on every endpoint.

online_shop/
  ├─ cart/          # Shopping cart logic
  ├─ coupons/       # Discount code engine
  ├─ products/      # Product catalogue
  ├─ orders/        # Order management
  ├─ payments/      # eSewa / PhonePe / COD
  ├─ wishlist/      # Saved products
  ├─ admin_dashboard/ # Chart.js analytics
  ├─ notifications/  # Email system
  └─ config/         # Django settings
